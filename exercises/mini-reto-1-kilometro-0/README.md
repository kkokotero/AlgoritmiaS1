# MiniReto 1 · Kilómetro 0: el alquiler sin ambigüedades

Trabajo individual para la asignatura de Algoritmia. Describe el proceso de alquiler
de una bicicleta en **Rueda Libre** como un algoritmo en lenguaje natural, lo prueba
con un compañero y corrige las ambigüedades encontradas.

> El enunciado pide un repositorio público `rueda-libre-algoritmia` con `README.md`,
> `bitacora.md` y `algoritmos/`. Aquí esa estructura vive como carpeta dentro del
> repositorio del curso.

## Estructura

```
mini-reto-1-kilometro-0/
├── README.md      ← este archivo
├── bitacora.md    ← entregable: versiones del algoritmo, ambigüedades y análisis
└── algoritmos/
    ├── alquiler-bicicleta-v1.md   ← primera redacción (con ambigüedades)
    └── alquiler-bicicleta-v2.md   ← versión corregida
```

## Contenido

- [Bitácora](bitacora.md) — contexto, versión 1, ambigüedades encontradas en el
  intercambio, versión corregida, justificación de las cinco características de un
  algoritmo correcto (precisión, finitud, orden, determinismo y efectividad) y los
  cuatro pilares del pensamiento computacional.
- [Algoritmo v1](algoritmos/alquiler-bicicleta-v1.md) — primera versión, sin inicio,
  sin fin y sin decisiones.
- [Algoritmo v2](algoritmos/alquiler-bicicleta-v2.md) — versión corregida con inicio
  y fin explícitos, decisiones (por ejemplo, qué hacer si no hay bicicletas) y ciclos
  acotados.

## Criterios cumplidos

- [x] Repositorio con `README.md`, `bitacora.md` y la carpeta `algoritmos/`.
- [x] La bitácora contiene la primera versión, las ambigüedades del compañero y la versión corregida.
- [x] El algoritmo corregido tiene inicio y final claros, e incluye decisiones.
- [x] Cada una de las cinco características está justificada con un fragmento del propio algoritmo.
- [x] Los cuatro pilares del pensamiento computacional están identificados en el proceso de alquiler.
